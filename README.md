# TestCaseSDA

Тестовое задание на ASP.NET Core .NET 10.

REST API обрабатывает HTML-страницу, выполняет поиск элементов по CSS-селектору и email-адресов, расшифровывает AES-256 данные и сохраняет найденные элементы в PostgreSQL.

Основная разработка ведётся в ветке `develop`, итоговая версия находится в `release`.
